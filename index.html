Rules & map exchange

Generation follows the world-scale procedure in Traveller5, chart 11, page 49. Terrain and feature choices use pages 46–47. Small worlds limit the number of placements.

Use traveller-trading 1.24.0+ to import edited maps with features. Existing version-1 JSON is supported.

Markers use readable abbreviations listed in the map legend; they are simplified symbols.
